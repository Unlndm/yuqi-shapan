# 驭棋沙盘

小米 Vela 快应用 · 手环/手表多棋种棋类游戏合集（跑道屏优先适配）。

## 系统特性

- **对战模式**：人机（默认按最近 5 局战绩升降档，可在设置页「对手强度」锁定简单 / 普通 / 困难）/ 双人同机轮流（**11 个**对局玩法均已支持；蛇棋本轮加入双人。2048 / 数字华容道 / 扫雷 / 推箱子 / 数独 / 迷宫 / 找不同为单人玩法，无模式选择 —— 单人玩法以 `mode=solo` 记录，进入战绩「单人通关」，不计入胜率分母；狼人杀为人机推理局）
- **匹配加载页**：掷骰演出后展示本局对手强度（仅人机）
- **随机执子**：棋类每局随机分配黑白；大富翁 / 飞行棋固定蓝方先手
- **战绩大厅**：19 款玩法的总局数/胜场/胜率（玩家视角，单人通关不计入胜率分母）+ 分棋种战绩（单人玩法显示「单人通关」行）+ 最近对局
- **赛季与棋币（2026-10-24）**：主页顶部「第 N 赛季 · 棋币 N」条进入赛季页。人机 / 双人对局结束自动发币（人机 胜 20 / 和 10 / 负 5；双人 15 / 8 / 4），结束弹窗显示本局棋币；5 条一次性赛季任务（完成 6 局 / 4 胜 / 3 连胜 / 4 种玩法 / 5 局人机，奖励 60~100 币，任务行带进度条，完成需手动领取）；赛季商店买**免狱卡**（80 币，大富翁出狱）与**重掷券**（60 币，飞行棋掷骰后可重掷一次）；棋币可解锁**琥珀**（200）与**绯红**（300）配色；每日挑战、终身成就、残局奖励、皮肤购买与新玩法结算全部写入同一棋币账户。本赛季为**第 1 赛季「初执棋子」**（`SEASON_ID=1`），赛季号每次发版手动 +1；**换季只重置赛季任务**，棋币 / 道具 / 已解锁配色 / 皮肤 / 成就 / 每日连续天数永久保留
- **每日挑战**：主页赛季条第二行显示今日挑战状态。赛季页按本地日期在 **19 款玩法**间轮换，并用日期种子驱动该玩法的全部随机项（骰子、卡牌、AI 并列决策、单人棋盘 / 关卡 / 题号、狼人杀身份分配）——同一天重新进入时玩法、局面与 AI 决策完全一致；当天首次完成发 **40 棋币**并累计连续挑战天数，失败可无限重试、同日不重复发币，跨日自动切换
- **闯关模式（2026-10-24）**：主页与赛季页均有入口。**8 章 × 10 关 = 80 关 / 240 星**，覆盖全部 19 款玩法（每条玩法至少 4 关；2026-10-31 新增第 7 章「试炼」与第 8 章「封王」）。每关有独立目标与星级门槛：通关 1 星，按手数 / 步数 / 用时 / 得分追 2~3 星；首次拿到 ≥1 星发首通棋币（20~40）并解锁下一关；星级只增不减，重玩可刷新最高星。关卡按难度固定 AI 强度，内置关卡型玩法固定子关卡（迷宫 3/10/18、找不同 5/20/35、推箱子 3/10/18），狼人杀按关卡 id 固定身份分配。进度 `campaign_state` 独立存档，另接入 5 项闯关终身成就
- **终身成就**：**48 项**（对局 8 / 棋种 9 / 赛季 8 / 收集 8 / 每日 5 / 残局 5 / 闯关 5），达标自动解锁并发放棋币、每项只发一次；进度与解锁状态终身保留，换季不重置
- **皮肤与收集**：棋盘底材 3 套、骰子皮肤 3 套、棋子样式 2 套、整页底色 2 档（素色 / 层次），共 **10 套**；棋币购买 / 装备 / 持久化，重复购买不扣费，素材缺失时回退默认。本轮新增 18 张 PNG 素材与 4 个新玩法图标
- **残局**：象棋 / 五子棋 / 围棋各 10 题，共 **30 题**；每题有目标与步数上限，防守方由 AI 按题解最优应对；支持提示（只显示下一手、不代落子）、重试、最佳步数记录，首次完成奖励 **60 棋币**
- **MD3 配色**：经典紫/静谧绿/深海蓝 × 深色/浅色 + 2 套可解锁配色（琥珀 200 棋币 / 绯红 300 棋币）；文字与底色严格按 MD3 配对（primaryContainer 用 onPrimaryContainer），五套配色深浅双模式实测对比度全部 ≥ WCAG AA 4.5:1
- **表面层级**：页面 `surface` → 信息卡 / 行卡 / 玩法卡 `surfaceContainer`（`theme.cardBg`）→ 弹窗、抽屉、底栏 / tab 坞 `surfaceContainerHigh`；棋盘空地仍与页面同色，不铺 tint。改版前信息卡与页面同色、层级只靠间距，2026-10-30 重构后恢复三级表面（层次底皮肤整体再抬一阶）。
- **体验**：棋盘全屏（缩放查看，摄像机式滚动）、落子自动居中、AI 思考延迟、将军提示、结束弹窗、对局常亮、震动反馈（可调强度）；**黑白棋单方无子可走时回合胶囊会显示「X 方无子可走 · 轮空」1.6s**（此前回合停在同一人身上，容易被当成卡住）；**黑白棋人类回合会用小圆点标出全部合法落点**，终局写明「盘满 / 一方无子 / 双方无子可走 · 黑X : 白Y」；**围棋停一手后胶囊会提示「X 方停一手」**（棋盘不落子，否则容易被当成点了没反应）；**国际象棋增加三次重复局面判和**（局面签名 = 棋子布局 + 行棋方 + 易位权旗标 + 过路兵目标，计数在走子栈上，悔棋自动回落）；**国际象棋兵升变可选**（兵进底线先弹「后/车/象/马」四选一，选定才落子；AI 搜索仍走缺省升后、不扩分支）；**大富翁竞拍落槌有震动反馈**（成交强震、流拍短震 —— 竞拍全程无气泡，震动是唯一即时反馈）；**大富翁 / 飞行棋盘面按屏幕纵横比自动分格**（24 / 28 格在上下与左右之间重新分配，格子仍为正方形、缝隙均匀、默认档继续贴满屏幕；例如跑道屏大富翁为上下 4 格、左右 10 格，缝隙 4–6px）
- **消息与决策（大富翁 / 飞行棋）**：**不需要确定/取消的播报**走**系统 Toast**（`@system.prompt` 的 `showToast`，manifest 已声明 `system.prompt`）；**需要玩家决定或要看结果**的一律走页内弹窗 —— 掷骰前弹「投骰子 / 取消」，买地、拍卖、债务清偿、资产管理、机会/命运卡面、终局各一个弹窗，**同一时刻只弹一个**（`dlg` 单字段驱动，避免堆叠）。顶部跑马灯播报已移除。⚠️ **竞拍是明确例外（玩家反馈：竞拍的气泡一闪一闪浪费时间）**：拍卖相关事件在引擎里统一带 `kind: 'auction'`，页面把这一类从 Toast 队列里滤掉 —— **拍卖全程没有任何消息气泡**；实时叫价改由**环内状态行**播报（`拍卖 $最高价`，颜色跟随领先者），成交结果由**盘面归属色 + 资金板**体现；AI 出价/放弃的间隔也从 600ms 压到 240ms。对应的「事件契约」写进了 `tests/rules-monopoly.js`，改事件文案/kind 时会立刻被测到
- **AI 强化（2026-10-24）**：① **根级 α 剪枝** —— normal/hard 根节点从「每个候选全窗口」改为「用当前最优分做 α 窗口」，只有严格更优的着法才记录（easy 继续全窗口收集并列最优，保留弱化随机）；② **历史启发** —— β 截断按 `depth²` 记分，后续节点优先重试该着法，配合既有 killer moves 提高剪枝率；③ **按分支数抬高深度上限** —— 全局 easy/normal/hard = 1/3/5，象棋 1/3/4、黑白棋 / 五子棋 / 围棋 1/3/6、四子棋 1/4/7、井字棋 9 层全解，均由 300/500ms 预算与迭代加深兜底。实测（hard，apply 调用数≈搜索节点）：五子棋 9×9 **500ms / 34.6 万**、象棋开局 **500ms / 3.8 万**、黑白棋 8×8 **105ms / 0.98 万**、四子棋 **106ms / 8.4 万**、围棋 9×9 **347ms / 5.8 万**。骰子玩法同步强化：**飞行棋 AI 会避开落在对手 1~6 格射程内的落点**（危险 -18 分）；**大富翁 hard 会为成套最后一块提高买地与竞拍上限**（买地留 20 即可、竞拍 1.6× 地价；非成套仍为 1.2×）。新增断言：象棋 Qxf7# 一步杀、飞行棋安全落点、大富翁成套决策。**新玩法复用同一套搜索**：国际跳棋 / 斗兽棋走 `core/ai.js` 的 negamax + 迭代加深 + 时间片；每日挑战通过注入日期种子，让 AI 并列决策也可复现。
- **迷宫像素风（2026-10-31）**：沿用废弃像素项目的「构建期烘焙」思路，把 25 张迷宫地图离线烘成 16px tilemap（`src/common/img/maze/m01.png`~`m25.png`），运行期只显示 1 张底图 + 玩家/道具图标；墙/地板来自 Kenney Roguelike RPG Pack（CC0），玩家 16×16 小人复用像素项目素材，钥匙/宝石/陷阱/药水/锁为程序化像素图标。网格 gap 归零对齐 tile，HUD/摇杆/按钮改直角/小圆角。
- **2026-10-31 交互 / 质量 / 内容批**：① **方屏开始页**（仅 6 个对局页的 idle 态）改为左上返回 + 右侧标题，底部旧「返回」删除、「玩法介绍」独占一行；**对局中的游戏界面不渲染该顶栏，仍保持全屏棋盘 + 抽屉**；② 2048 / 数字华容道支持**手势滑动**，侧滑返回一律吞掉（退出只走左上角）；**2048 直接移除四向十字键**，底部只留「新局 / 档位」，棋盘可视面积明显增大；③ 迷宫 20 → **25 关**，方向键改为**虚拟摇杆**（高画布 84 / 矮画布 56，死区 0.30 / 180ms 连走 / 手指超出钳在圈上）（16~20 的镜像复刻，全部通过可达性校验），找不同 40 → **45 关**（36~40 的 180° 镜像，差异坐标同步旋转）；④ 大富翁 / 飞行棋棋盘格、金额板、状态行圆角与字距统一，棋子移动与骰子落定加轻动效；大富翁点任意格新增「地价 / 当前租金 / 归属」信息卡；飞行棋选择行动时把候选预计落点在棋盘上高亮；蛇棋 HUD 改表面卡片 + 双方进度条 + 棋子逐格过渡 + 骰子落定动效；找不同 HUD 增加 5 枚差异进度点。
- **方屏开局页重构（2026-10-31，玩家要求「除了胶囊屏，开始页面重构」）**：6 个对局页（game / aeroplane / monopoly / draughts / jungle / snake）在 `shape: rect` 下改为紧凑双行布局：

  - **对战模式一行两枚 84×34**；
  - **棋盘大小一行四枚 40×34**（7×7 / 9×9 / 11×11 / 13×13 一排放下，13×13 仍完整）；

  - 「玩法介绍 / 返回」改为并排 84×34，不再上下各占一行；

- **AI 人类大脑模型（2026-10-31，玩家要求「优化 AI 模拟人类大脑组成」）**：把 AI 从「只会算」拆成六层，只在异步对局的根节点选点生效（同步 `chooseMove` 仍保持纯搜索，供测试与残局最优应手）：
  - **感知 attention**：根候选按分数窗口收缩，难度越低窗口越宽、越容易漏看；
  - **直觉 intuition**：保留一步胜 / 必堵 / 双威胁的根级预检，先于深搜；
  - **推理 deliberation**：原 negamax + 迭代加深 + 时间片；
  - **情绪 mood**：用当前评估判断领先/落后，落后时提高攻击性、领先时更保守；
  - **记忆 memory**：一局内记录手数、最近评估、玩家落点；手数越多疲劳越高，失误率缓慢上升；
  - **人格 persona**：每局随机「沉稳 / 好战 / 灵动」，改变攻击性、注意力与思考节奏（沉稳慢约 180ms、好战快约 140ms）；
  - **疲劳 fatigue**：`blunder = 基础失误 + 手数×0.0012 + 玩家里程×0.0004`，上限 0.06。
  - 难度参数：easy 注意力 0.56 / 失误 0.16，normal 0.78 / 0.07，hard 0.94 / 0.025；hard 仍会偶尔选次优，但**已证必胜时不会“走神”送掉**（`best > WIN_SCORE` 直接走胜着）。

- **屏幕安全区（胶囊屏 / 跑道屏）**：胶囊屏的短边是**半圆**，外接圆半径 `R ≈ 屏宽/2 = 96`（设计像素）—— 在高度 y 处屏幕可见区的左右边界是 `xmin = R − √(R² − (R − y)²)`，**越靠左右两端可见高度越低**（⚠️ 玩家真机截图像素取证：按 `top:4px` 放顶部浮层时，整行都落在圆弧外被屏幕切掉）。故所有**顶部浮层/顶栏**在胶囊屏上按「元素最左沿 x」反解安全值：
  - 棋类对局页顶部浮层（菜单按钮 44 + 间距 6 + 回合胶囊约 90 ≈ 整行 140 宽居中 → 左沿 x=26）：`top: 4px → 32px`（`xmin(y)=26` 反解得 y≥30.3）；菜单按钮 2026-10-23 由 20 高加到 34，浮层底边 66，棋盘让位量随之 `17 → 60`（`PILL_CLEAR_CAPSULE`）；同时修正 `layoutBoard()` 的摄像机定位 —— 原写法只按 `(boardH−vpH)/2` 居中、没算棋盘在舞台里的上偏移 `padY`，整盘比屏幕高时会把上偏移「滚掉」（首行压在胶囊下、底部多出空白），现改为 `padY() + (boardH−vpH)/2`，与 `centerOn()` 口径一致。**方屏不变**（`top:4px`，浮层只有 88 宽的胶囊；方屏是矩形屏，不适用半圆口径）。
  - 2048 / 数字华容道顶栏（最左件是左沿 x=8 的「返回」）：`top: 2/4px → 58px`（反解得 y≥57.6）。高画布上棋盘受宽度限制，抬顶栏不吃棋盘空间；矮画布复算无溢出（胶囊 471/490/355 格宽 41，300 格宽 34/55）。
  - 同时把 2048 的「矮画布」阈值与 `utils/screen.js` 的 `compact`（`designH<400`）对齐 —— 抬顶栏后 340~400 这一段若仍用十字键（竖向 130px）会把棋盘挤到格宽 25px。
  - **环内元素（大富翁 / 飞行棋的金额板、骰子、菜单按钮）不受影响**：它们位于屏幕竖直中部，`xmin = 0`；底部抽屉只在两端丢圆角（标签居中、可点），未做抬升
- **胶囊屏「整宽单列」口径（2026-10-18 补漏）**：胶囊屏属于**竖向窄屏**，凡是并排两枚以上的**可点控件**都必须改成「整宽单列」，否则每枚只有约 68px 宽、手指点不准（玩家反馈：大富翁 / 飞行棋的开局设置模式选项点不到）。现状：棋类对局页与 2048 / 数字华容道 / 扫雷的设置区早已整宽单列；**大富翁的 pill 媒体查询此前只改了 `.hud`、飞行棋此前**完全没有 pill 媒体查询**，故这两页的模式 chip 在胶囊屏仍是 `flex-wrap` 的并排两列 → 本轮补齐（`.chips` 改 `flex-direction: column` + `width:168px`，`.chip` 同步整宽），并用审计断言 `shape:pill-shaped` 兜住「pill 媒体查询被误删」的回归。**页内大按钮**（2048 / 华容道的「新局 / 洗牌重开」与其并排的「档位」）也都保证 ≥34px 宽

### 正式版打包注意事项

1. 签名证书位于 `sign/private.pem` / `sign/certificate.pem`（10 年期自签）。
2. **不要加 `--optimize-css-attr`**：它会把 CSS 属性名压成短名（`flexDirection` → `fD`），
   机型端运行时不认就整包丢样式，全部元素回落默认 `flex-direction: row`（实机表现为「布局变横排」）。
   `release:jsc` 已固定为 `aiot release --enable-jsc --drop-console true`。
3. `release:jsc` 直连 `aiot release --enable-jsc`，构建在 `D:\andlua\.temp_yiqi`
   临时目录完成（工具链自动迁移，构建结束拷回本项目 `dist/`）。
   **目录名须为纯 ASCII**：路径含中文时 `--enable-jsc` 会报 `stat failed`，
   此时需把 `src / sign / package.json` 复制到纯 ASCII 路径后在该目录构建。
4. `aiot release` 会**清空 `dist/`** 且只留本次产物 —— 需要 debug 包时先跑
   `npm run build`（审计脚本校验的是 debug 包）；要同时留多份产物，构建后手动改名保存。
5. 正式包内页面源码全部替换为 `.jsc` 字节码（不可直接反读）；
   若怀疑字节码有问题，可出无 JSC 版对照（`aiot release --drop-console true`，包内为可读 `.js`）。

规则层为纯函数（node 直接可测），渲染层只认「棋盘几何 + 棋子列表」；
新增棋种只需：rules/ 新模块 + config.js GAME_TYPES 一条 + （棋盘类）规则注册表一行；
**独立页玩法还要在 manifest.json 的 `router.pages` 注册该页**（漏了这步 `aiot build` 不会编译它，构建照样「成功」）。
