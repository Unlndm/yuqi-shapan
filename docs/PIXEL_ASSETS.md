# 像素素材来源

- 迷宫墙 / 地板 tile：Kenney **Roguelike RPG Pack**（CC0，可商用、免署名），经 `重制版-宠伴像素风/tools/_tiles_used.png` 裁切、调色后烘成 16px tilemap。
- 玩家 16×16 像素小人：来自 `重制版-宠伴像素风/src/common/world/player.png`，随本项目一起使用。
- 钥匙 / 宝石 / 陷阱 / 药水 / 锁：为迷宫专门程序化绘制的 16×16 像素图标。
- 墙 / 地板 tilemap：`src/common/img/maze/m01.png` ~ `m25.png`，由 `rules/maze-levels.js` 离线烘焙；修改地图后需重烘。
